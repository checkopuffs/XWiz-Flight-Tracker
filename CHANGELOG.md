# Development history

Milestones summarized from the project development conversation; not a version-control history.

- **V0.9 (in progress)** — Preliminary display and ESP32 fit gauges; final enclosure not designed or validated.
- **V0.8.1** — Forward declarations to resolve Arduino compile issue; owner reported 10/10 functional acceptance tests passed.
- **V0.8** — Local web control, persistent settings, adjustable radius, four themes and alert/route toggles.
- **V0.7** — Blue Horizon: bearing, nearest aircraft, spotter mode, 5 NM proximity indication and larger tracking radius; improved JSON allocation and timeout handling during troubleshooting.
- **V0.6** — ADSBDB callsign route lookups and caching.
- **V0.5** — Automatic flight details and radar rotation.
- **V0.4.1** — Framebuffer, hardware SPI and background networking to improve display behavior.
- **V0.4** — Live position data from ADSB.fi.
- **V0.3** — Wi-Fi connectivity.
- **V0.2** — Simulated animated radar.
- **V0.1** — Display and color test.

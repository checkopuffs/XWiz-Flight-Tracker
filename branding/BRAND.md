# XWiz brand guide

**Build. Learn. Innovate.**

XWiz is a proposed personal maker identity, not a claim of company registration or trademark clearance. The core mark uses geometric lettering; the PNG is suitable for README banners, the SVG is editable, and the monochrome wordmark contains only filled paths for CAD experiments. Import into CAD and size to available flat area; test small letters before printing. Suggested black housing and electric-blue raised lettering, at least 0.8 mm wide strokes for a 0.4 mm nozzle.

| Color | Hex | Use |
|---|---|---|
| Electric Blue | #38BDF8 | Primary accent |
| Midnight | #080F19 | Dark background |
| Gunmetal | #334155 | Secondary surfaces |
| Ice White | #E2E8F0 | Text and contrast |

Suggested project labels: XWiz Flight (aviation), XWiz Tactical (sensor projects), XWiz Robotics, XWiz Buddy, XWiz Homelab, XWiz AI. These names are proposals, not separate companies. Check name and trademark availability before any commercial use.
